## ⚡ Quick Start (3 Steps)

### Step 1: Run the Inventory
```powershell
# Open PowerShell AS ADMINISTRATOR
cd "$env:USERPROFILE\Documents\DIGITAL_ASSET_AUDIT\00_SETUP"
.\Create_Drive_Inventory.ps1
```

**Output:** 3 files in `Documents\DIGITAL_ASSET_AUDIT\`
- `I_drive_asset_inventory.csv`
- `C_drive_asset_inventory.csv`
- `AUDIT_SUMMARY.txt`

### Step 2: Sanitize CSVs
Open in Excel. Delete any rows with:
- Passwords / logins
- Bank / tax / financial docs
- Legal contracts with real names
- Client files
- Personal photos / ID scans

See `SAFETY_AND_PRIVACY_GUIDE.md` for complete checklist.

### Step 3: Follow the 30-Day Plan
Open `30_Day_Launch_Plan.md`. Execute daily tasks. First revenue in Week 2.

## 🔒 Privacy First

This system **NEVER** reads your file contents. It only collects:
- File names
- Folder paths
- Extensions
- Sizes
- Modified dates
- Keyword matches from filenames

You control what gets shared. Everything runs locally.
